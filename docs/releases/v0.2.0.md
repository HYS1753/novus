# Novus 0.2.0

Windows x64 태블릿용 Novus 업데이트입니다.

- Novus 창 모드·전체화면 전환과 서비스 플레이어 전체화면에서 독 숨김/복원을 지원합니다.
- 실행 중인 서비스 앱을 독에서 확인하고 닫을 수 있습니다.
- 내장 영상의 플로팅 조작 바·자동 숨김·뒤로가기·종료 동작과 이미지 화면 맞춤·로딩 표시를 개선했습니다.
- 설정에 자동 업데이트 ON/OFF, 수동 확인, 다운로드 진행률·취소, 설치 확인을 추가했습니다. 자동 업데이트는 새 버전을 확인·다운로드하며 설치와 재시작은 직접 선택합니다.
- 테마·독 위치·자동 업데이트 설정을 재시작 후에도 유지합니다.

## 설치와 업데이트

아래 Assets의 **novus_0.2.0_x64-setup.exe**를 다운로드해 실행하세요. 현재 Windows 사용자 계정에 설치합니다.

기존 0.1.0에는 updater가 없으므로 최초 한 번은 새 EXE를 수동 설치해야 합니다. 기존 앱을 종료하고 같은 사용자 계정·설치 위치에 설치하세요. 기존 MSI 설치본의 자동 이전은 검증하지 않았습니다.

`.exe.sig`, `latest.json`, `SHA256SUMS`, `release-source.json`은 업데이트 서명·다운로드 정보와 빌드 추적 파일입니다. 직접 실행할 파일은 EXE 하나입니다.

Windows x64 NSIS 설치본을 배포합니다. macOS/Linux 설치 파일은 이번 Release에 포함하지 않습니다. 업데이트 파일 서명은 Windows 게시자 인증서(Authenticode)와 별개이며, 게시자 인증서는 구성하지 않았습니다.
