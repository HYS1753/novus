# Novus 1.0.0

Windows x64용 Novus의 첫 1.0 정식 릴리즈입니다. 사진 중심의 새 홈과 미디어 탐색 화면을 적용하고, 앱과 설치 파일에 Novus NV 아이콘을 사용합니다.

## 달라진 점

- 사진 프레임과 오늘의 대시보드로 홈을 새롭게 구성했습니다. 실행 중인 서비스를 확인하고 이어 보거나 닫을 수 있습니다.
- 처음 실행할 때 언어와 태블릿형/TV형 보기를 선택할 수 있습니다. 한국어·영어·일본어·중국어와 시스템·라이트·다크 테마를 지원합니다.
- 갤러리에 사진 타임라인·폴더 탐색·영상 선반을 추가했습니다. 사진의 방향 정보를 반영하고, 확대·넘김·슬라이드쇼와 로딩 표시를 제공합니다.
- 파일 탐색기를 새 디자인으로 통일했습니다. 이름 검색·정렬·목록/아이콘 보기와 파일 열기를 지원합니다.
- 내장 영상은 화면 위에 뜨는 조작 바를 사용합니다. 조작 바는 약 3초 뒤 숨겨지고 화면을 누르면 다시 나타납니다. 창 전체화면과 서비스 플레이어 전체화면, 독 숨김·복귀를 지원합니다.
- 설정에서 Windows 부팅 시 자동 시작, 홈 사진 폴더, 날씨 지역, 독 위치 등을 조정할 수 있습니다.
- 업데이트 설정과 진행률·취소·설치 확인 화면을 새 디자인에 맞췄습니다. 자동 업데이트는 새 버전을 확인·다운로드하며 **설치와 재시작은 직접 선택**합니다.
- 기존 테마 설정을 새 설정으로 옮기고 로그인·독 위치·업데이트 설정을 유지합니다. 작은 창에서도 주요 설정의 터치 영역을 확보하고, 긴 폴더 목록은 페이지로 나눠 표시합니다.

## 설치와 업데이트

아래 Assets의 **novus_1.0.0_x64-setup.exe**를 다운로드해 실행하세요. 현재 Windows 사용자 계정에 설치합니다.

- 기존 **0.2.0 NSIS 설치본**은 앱 설정에서 업데이트를 확인하거나, 기존 앱을 종료하고 새 EXE를 같은 사용자 계정·설치 위치에 설치하세요.
- 새 디자인을 처음 실행하면 언어·보기·사진 폴더 온보딩이 한 번 표시됩니다. 기존에 저장한 설정과 서비스 로그인 프로필을 초기화하지 않습니다.
- 기존 **0.1.0**에는 updater가 없으므로 새 EXE를 한 번 수동 설치해야 합니다. MSI 또는 다른 사용자/관리자 범위 설치본의 자동 이전은 검증하지 않았습니다.

`.exe.sig`, `latest.json`, `SHA256SUMS`, `release-source.json`은 업데이트 서명·다운로드 정보와 빌드 추적 파일입니다. 직접 실행할 파일은 EXE 하나입니다.

## 지원 범위

이번 Release는 **Windows x64 NSIS 설치본**을 제공합니다. macOS/Linux 설치 파일은 포함하지 않습니다.

Windows QA 설치본에서 실제 업데이트·재시작, Netflix 로그인과 설정 보존, 사진 및 MPV 영상 재생을 검증했습니다. 실제 Surface Pro 4의 성능과 Netflix 유료 영상 DRM 재생은 별도 검증 대상입니다. 업데이트 파일 서명과 Windows 게시자 인증서(Authenticode)는 별개이며, 게시자 인증서는 구성하지 않았습니다.
