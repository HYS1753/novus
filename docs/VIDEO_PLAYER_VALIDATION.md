# 로컬 동영상 플레이어 검증 기준

이 문서는 Windows Surface Pro 4 m3 / Intel HD 515 / 4GB RAM과 macOS에서 `libmpv` 기반 인앱 플레이어를 검증하는 절차입니다. Novus는 Windows에서 `libmpv` DLL이 발견되거나 macOS에서 묶인 dylib가 로딩되면 네이티브 영상 표면을 선택합니다. 엔진이 없으면 갤러리에서 HTML `<video>`를 사용합니다. 재생 오류 시 설치된 mpv 또는 OS 플레이어를 사용자 선택으로 열 수 있습니다. 바이너리는 Git에 포함되지 않으며 아래 표의 실제 화면 출력·성능 결과는 아직 측정되지 않았습니다.

## 1. 비교 환경

- 같은 Windows 설치, 그래픽 드라이버, 전원 모드, 화면 해상도, 영상 파일에서 **독립 mpv → 현재 Novus → `libmpv` 통합 Novus** 순서로 측정합니다.
- macOS도 같은 파일로 독립 mpv와 Novus를 비교합니다. Intel Mac과 Apple Silicon Mac은 디코더·GPU 경로가 다르므로 결과를 분리하고, 네이티브 영상 영역의 배율·전체 화면·잠자기 복귀를 각각 확인합니다.
- 각 파일은 로컬 SSD에 두고 첫 실행(차가운 캐시)과 재실행(따뜻한 캐시)을 구분합니다. 백그라운드 다운로드 및 다른 영상 앱은 종료합니다.
- mpv 버전, FFmpeg 빌드, Windows 버전, 드라이버 버전, 전원 연결 상태를 결과와 함께 기록합니다. `--hwdec=auto-safe`가 실제 하드웨어 디코딩을 선택했는지도 확인합니다.
- 설정의 ‘현재 나의 기기’에 표시된 OS·모델·CPU·RAM을 시스템 정보와 대조합니다. 표시된 기기 프로필은 재생 성능 결과를 구분하는 기준이며, 코덱의 하드웨어 지원 여부는 별도로 측정합니다.
- 재생 중 작업 관리자의 CPU, 메모리(프로세스별 작업 집합), GPU `Video Decode` 사용량을 기록합니다. mpv 통계의 프레임 누락, 영상/음성 싱크, 사용 디코더도 기록합니다.
- DRM 스트리밍 서비스는 로컬 플레이어 검증 범위에 넣지 않습니다.

## 2. 최소 시험 파일

| --- | -------- | ---------------------------------------- | --------------- | ----------------------------- |
| V01 | MP4      | H.264 8비트 / AAC                        | 1080p 30fps     | 기본 경로와 현재 WebView 비교 |

| V03 | MKV      | H.264 8비트 / AAC / 내장 SRT             | 1080p 30fps     | MKV, 자막 선택                |

실제 촬영·보유 영상에서 개인 정보가 없는 샘플을 사용합니다. 파일명, 코덱 프로파일, 평균·최대 비트레이트, 길이, 해시를 결과에 남깁니다. 확장자만으로 코덱을 판단하지 않습니다.

## 3. 측정 절차

1. Novus 시작 전 메모리를 기록하고, 갤러리 진입 직후 안정된 작업 집합을 기록합니다.
2. 각 파일을 세 번 열어 첫 화면 표시까지 걸린 시간과 성공 여부를 기록합니다.
3. 최소 10분 또는 영상 끝까지 재생하면서 프레임 누락, 음성 싱크, CPU·GPU 사용량, 최대 작업 집합을 기록합니다.
4. 10%, 50%, 90% 지점으로 탐색하고 재생 재개까지 걸린 시간 및 프레임 깨짐을 기록합니다.
5. 일시정지, 음량, 전체 화면, 자막·음성 트랙 전환, 갤러리 뒤로가기, 홈 이동을 확인합니다.
6. 플레이어를 닫고 30초 후 메모리와 디코더·자식 창·파일 핸들 해제 여부를 확인합니다. 열기와 닫기를 20회 반복합니다.
7. 시스템 절전 복귀, 화면 회전·배율 변경, Novus 창 크기 변경을 각각 확인합니다.

## 4. 통합 완료 기준

- V01–V09가 앱 안의 네이티브 영상 영역에서 열리고, 컨테이너나 코덱 문제는 사용자가 이해할 수 있는 오류로 표시됩니다. 손상 파일 V10에서 Novus가 종료되지 않습니다.
- V01–V04의 1080p 재생은 같은 기기의 독립 mpv와 비교해 프레임 누락·재생 지연이 뚜렷하게 악화되지 않아야 합니다. V05–V07은 하드웨어 지원 여부와 실측 결과에 따라 지원 성능 범위를 별도로 명시합니다.
- 영상이 Novus의 갤러리·독·조작 UI를 덮거나 포커스를 빼앗지 않습니다. 마우스와 터치 입력, 전체 화면, 배율 변경에서 위치가 맞습니다.
- 플레이어를 닫으면 네이티브 출력 창과 디코더가 해제되고, 반복 재생에서 작업 집합이 계속 증가하지 않습니다.
- 네이티브 영상 영역 아래 Novus 버튼에서 재생/일시정지와 10초 앞뒤 이동이 작동하고, 좁은 창에서도 버튼이 영상 표면 뒤에 가려지지 않습니다.
- 엔진이 없는 개발 환경, 디코딩 오류, GPU 장치 손실에서 갤러리와 대시보드 탐색이 계속 동작합니다.

측정값이 없는 항목은 통과로 간주하지 않습니다. 특히 4K, HEVC 10비트, AV1의 끊김 없는 재생을 하드웨어 검증 전에 약속하지 않습니다.
